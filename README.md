# Marcial Sanchis Agudo — personal website

Static multi-page site (researcher + founder: chaotic systems, turbulence, interpretable AI, Mama's Brain).
Served via GitHub Pages. No build step: edit the .html files, `style.css` and `assets/site.js` directly.

- `assets/site.js`: mobile nav, reveal-on-scroll, and the home-page flow field (tracers in drifting Lamb-Oseen vortices).
- `mb.html` is a short founder page; the full Mama's Brain site lives in its own repo (`mamasbrain`).
- `research/`, `work/`, `about/`, `contact/`, `writing/` only redirect old URLs to the `.html` pages.
